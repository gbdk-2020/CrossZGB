# SFX example

Plays different types of sound effect assets

FXHammer - cross-platform assets in SAV format, SAME asset files sound similar
VGM - platform-specific VGMs, Game Boy APU for the Game Boy, SN76489 for the Master System/Game Gear
WAV - Game Boy only

Also demonstrate the legacy PlayFx() function, it is Game Boy only and obsolete, it is not recommended to use it
